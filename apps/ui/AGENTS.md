# UI 目录规则

- 先根据 `README.md` 判断目标是 `desktop` 还是 `web`；用户明确说“桌面 UI/终端”时禁止修改 `web`，明确说“网页/浏览器/BFF”时禁止修改 `desktop`。
- `desktop` 的 Binance 风格只复用信息层级与操作习惯，不复制品牌资产；行情、订单、仓位和资产必须来自现有真实投影，缺数据时显示空态，不伪造数值。
- `web` 继续遵守其目录内 `AGENTS.md` 的 Next.js 版本说明与安全边界。
- 两端不得直接持有交易所凭证或绕过 Control/Executor 下单；跨端共用字段先进入协议 crate，不用两份同名本地类型掩盖差异。
