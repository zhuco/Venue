# VenueFlow 指标未通过的验收门

现行功能、作用域和数据来源见 [VenueFlow 桌面契约](VENUEFLOW.md#图表指标与布局)，源码入口见 [CODEMAP](CODEMAP.md)。本页只保留仍需验证的行为与性能门；历史实施步骤和逐次测试流水由 Git 记录。源码、离线测试、构建、公开数据回读、原生窗口及生产服务是不同证据。

## 已有证据范围

截至 2026-09-28，本地工作区的 `venue-indicators` 79 项、`venueflow --lib` 384 项测试通过，后者有 6 项既有忽略；桌面 all-targets、WASM 预览源码检查及桌面 release 构建通过。此前只读原生窗口走查显示 Binance DOGE/USDC 六周期及 Bybit 已存在合约的行情、Funding/OI；主合约公开 OI 当前值和完成 5m 历史经精确 HTTPS 代理回读。近期审计修复 OI 限流冷却、切换作用域时未完成标注、FR 端点越界、AVWAP 缺口绘线和 Profile 极小量负分桶。上述证据属于本地未提交源码的既有检查，不证明本次生产版本或下述门已通过。

## 数据与交互验收

- 同一完整 `MarketSelection.binding` 的 1m 来源在 1m／5m／15m／1h／4h／1d 产生一致的热图时间身份；验证已收盘确认、形成中预览、tick、缺口、分页、缓存修订与跨场所隔离，不沿时间汇总相对强度为金额。历史视窗必须按需补充同源分钟事实，缺失区间显示覆盖不足。
- UTC 日周水平位和 Pivot 验证日界、周一、跨年、闰日、完整前期与历史无前视。Delta/CVD 验证真实主动买量、缺方向、重复／乱序、Daily 与 Loaded Continuous 重置、前补和预览不双计。自动 S/R 验证右侧收盘确认、同价 tie、合并宽度、触碰、突破／回测、老化和高周期未收盘不提前确认。
- Visible 与 Fixed Range Profile 在同一时间范围的 POC／VAH／VAL 相同；验证体积守恒、零量与缺量、价格精度、70% 价值区、端点编辑、切周期不漂移及“估算”标识。至少三条 AVWAP 验证锚点真实时间、历史加载、缺口断线、跨周期、切换来源隔离、拖动取消与重启恢复。ATR% 历史悬停使用当时收盘价。
- Funding/OI 验证单位、单边／双边口径、当前与历史样本时间、旧异步结果拒绝、stale、429／断线恢复、无数据空态和旧来源不闪现。Binance DOGE/USDC 必须使用精确 DOGEUSDC 合约；Bybit、Gate、OKX 核对原生历史的起止时间与分页；Bitget、Hyperliquid 只展示本机真实观察起点，不虚构启动前 5m 历史。缺少比较基准时变化显示 `—`，1m 图不插值出 1m OI。
- 公开 K 线与 OI 本地页验证完整 binding／周期隔离、损坏回源、重启只补缺口、缓存命中不重复下载、缓存预算淘汰与无消费者取消。默认只加载约 120 根显示 K 线；长日线热图只在用户明确请求后按可见范围补分钟事实。旧设置、显式关闭、脚本原意、三锚点与 FR 范围在保存／取消／重启后保持；分析操作不得返回交易选价或发出命令。

## 原生窗口验收

1. 在实际 Binance DOGE/USDC 1m 窗口核对 K 线身份、热图估算、PDH/PDL/SR、Funding、ATR%；同范围打开 VR 与 FR Profile 比较 POC/VAH/VAL，开启 Delta/CVD 与 OI，建立并编辑三条 AVWAP。
2. 保持同一历史段切换 5m→15m→1h→4h→1d→1m，检查时间与价格轴、热图覆盖、日周水平、CVD 模式、锚点与 Profile 区间。再切 DOGE/USDT、BTC/USDC 及另一场所真实存在的合约，确认旧数据与标注不跨 binding。
3. 向左浏览跨日／周历史，检查按需加载、缺口与错误空态；关闭并重启桌面核对设置与手工标注。核对价格轴拖动、缩放、十字光标、盘口和订单／仓位／成交标签。不以真实下单完成指标验收。

目前只有六周期与一次跨场所的只读画面证据；三锚点、双 Profile 数值、重启保存及故障画面尚未完成全项原生走查。离线 egui 和序列化测试不能替代该门。

## 性能与异常门

在相同 release、窗口／DPI、历史范围和网络下，分别比较 DOGE/USDC 1m 基础指标、增加 Profile／CVD／OI 及最大多图表布局：UI frame p95 ≤16.7ms、p99 ≤33.3ms，指标增加的 frame p95 ≤2ms；行情到画面 p95 不较基线恶化超过 10%。缓存切换 p95 ≤150ms，无缓存 100ms 内显示新作用域加载态；Profile 停止交互后 200ms 内完成已有缓存的结果。

全应用新增指标缓存目标 256 MiB，须同时测量分页、结果、异步输入和图形资源，末段 RSS 不持续上升；关闭指标、A→B→A、断线重连不累积 worker 或请求。覆盖 WS 断线、REST 超时／429、时钟偏移、合约不存在、历史不足、方向或 volume 缺失、OI/Funding 迟到、取消后晚到及缓存损坏，主图与既有交易 UI 保持可操作。局部 124 MiB 分钟源、64 MiB 异步输入和 56 MiB 图表结果配额只是实现边界，不能代替全应用测量。

原计划的连续 15 分钟采样、至少 100 次快速切换以及末 5 分钟 RSS 判断按用户要求停止，**本次不执行，也不标记通过**。短回归和 release 构建不能推断这些数值。恢复性能验收时记录基线、同机前后 p50/p95/p99、CPU、RSS、请求数、缓存命中和 worker 数，并另核对生产与本地版本。
